# Changelog

## 1.0.1
- Replaced the deprecated `use_container_width` setting with `width="stretch"`; minimum Streamlit is now 1.66.
- App footer and package now show the version number.
- README: live app link and a note that phone users should use "Upload a file" for the back camera.
- Added this changelog.

## 1.0.0
- First release: configurable OMR grading engine (any rows x columns grid, tested 5 to 30 questions),
  answer key, marks and optional negative marking, skipped / multiple-mark detection, grade bands,
  colour feedback on the original photo, upload / camera input, batch grading with CSV and ZIP export,
  printable sheet generator, 30 automated tests, Docker / Render / Streamlit Cloud deployment files.
